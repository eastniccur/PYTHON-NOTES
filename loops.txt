Loops allow you to repeat operations cleanly across collections or range conditions without writing repetitive code.

WHILE LOOP:   [ Keep running IF condition is True ]  ---> Infinite until flag breaks
FOR LOOP:     [ Walk through every item in collection ] ---> Stops automatically at the end

while vs for: Use for loops when you know the collection or sequence bound in advance (range(), list, dict). Use while loops when you need to repeat an action until a dynamic condition shifts to False.

break vs continue:

break: Completely exits the loop immediately.

continue: Skips the rest of the current iteration and jumps directly to the next item

The range() function is used to return a list of numbers. 
-->The range(start, end, step) takes three parameters: starting, ending and increment.

UPDATE-->update method adds the elements of the specified set to the current set.
